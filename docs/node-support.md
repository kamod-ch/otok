# Node.js support matrix

For overall release/status context see [2.x repository status](./2.0/status.md) (`docs/2.0/status.md`).

CI runs the full test suite on:

| Node.js | Status                      |
| ------- | --------------------------- |
| 20.x    | supported (LTS)             |
| 22.x    | supported (LTS, CI default) |

Workspace `engines.node` is `>=20`. Newer even majors are best-effort until added to CI.
