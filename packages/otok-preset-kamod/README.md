# @kamod-ch/otok-preset-kamod

Official Otok **kamod** scaffold preset (Kamod UI + Tailwind).

**Audience:** used by `create-otok` — applications normally do not install this package directly.

## Scaffold

```bash
pnpm create otok@latest my-app --variant kamod
```
