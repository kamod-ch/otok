# @kamod-ch/otok-preset-saas

Official Otok **saas** scaffold preset (auth, i18n, Kysely, validation, security, SEO).

**Audience:** used by `create-otok` — applications normally do not install this package directly.

## Scaffold

```bash
pnpm create otok@latest my-app --variant saas
```

Composes `@kamod-ch/otok-kit-saas` and related plugins during scaffold.
