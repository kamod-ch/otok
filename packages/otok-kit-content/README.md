# @kamod-ch/otok-kit-content

CMS-style pages kit built on `@kamod-ch/otok-content`.

**Audience:** application developers composing business kits.

## Usage

Kits are normally merged at scaffold time or via `mergeKits` from `@kamod-ch/otok-config`. Direct install is only needed when composing kits programmatically:

```bash
pnpm add @kamod-ch/otok-kit-content
```

See [Otok business kits](https://github.com/kamod-ch/otok/blob/main/docs/business-kits.md) and the [kits and presets guide](https://kamod-ch.github.io/otok/guides/ecosystem-kits-and-presets/).
