# @kamod-ch/otok-kit-admin

Users, roles, and org settings for Otok apps. Plain HTML routes — compose with `@kamod-ch/otok-kamod` for Kamod UI.

```bash
pnpm create otok my-app --variant crm --kit @kamod-ch/otok-kit-admin
pnpm --filter @kamod-ch/otok-kit-admin test
```

Conflicts with `@kamod-ch/otok-kit-marketplace`.

See [docs/extension-points.md](./docs/extension-points.md).
