# @kamod-ch/otok-plugin-fixture

Otok plugin fixture used by tests to exercise multiple plugin hooks.

**Audience:** maintainers and plugin authors — not recommended for application dependencies.

## Purpose

Provides a deterministic plugin implementation for unit and integration tests inside the Otok repository.

## Development

```bash
pnpm --filter @kamod-ch/otok-plugin-fixture test
pnpm --filter @kamod-ch/otok-plugin-fixture build
```
