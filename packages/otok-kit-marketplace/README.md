# @kamod-ch/otok-kit-marketplace

Marketplace listings and orders scaffold kit for Otok apps.

**Audience:** application developers composing business kits.

## Usage

Prefer scaffold or `mergeKits` rather than installing the kit alone:

```bash
pnpm add @kamod-ch/otok-kit-marketplace
```

See [Otok business kits](https://github.com/kamod-ch/otok/blob/main/docs/business-kits.md) and the [kits and presets guide](https://kamod-ch.github.io/otok/guides/ecosystem-kits-and-presets/).

## Maturity

Scaffold-level kit — review routes and migrations before production use.
