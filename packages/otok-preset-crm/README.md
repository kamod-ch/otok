# @kamod-ch/otok-preset-crm

Official Otok **crm** scaffold preset (CRM demo with mutations).

**Audience:** used by `create-otok` — applications normally do not install this package directly.

## Scaffold

```bash
pnpm create otok@latest my-app --variant crm
```

Composes `@kamod-ch/otok-kit-crm` during scaffold. See [business kits](https://github.com/kamod-ch/otok/blob/main/docs/business-kits.md).
