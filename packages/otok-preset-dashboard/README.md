# @kamod-ch/otok-preset-dashboard

Official Otok **dashboard** scaffold preset with admin-style components.

**Audience:** used by `create-otok` — applications normally do not install this package directly.

## Scaffold

```bash
pnpm create otok@latest my-app --variant dashboard
```
