# @kamod-ch/otok-preset-minimal

Official Otok **minimal** scaffold preset (counter demo, no UI library).

**Audience:** used by `create-otok` — applications normally do not install this package directly.

## Scaffold

```bash
pnpm create otok@latest my-app --variant minimal
```
