# i18n & accessibility — discussions UI

## i18n (`@kamod-ch/i18n`)

- Message schema: default locale tree in `src/i18n/messages/de.ts` → `DiscussionMessageSchema`.
- **One `createDiscussionsI18n({ locale })` per SSR request** — never mutate a global locale on the server.
- Loaders resolve locale via `resolveDiscussionsLocale()` (Accept-Language or `createDiscussions({ i18n: { resolveLocale } })`).
- Pass `locale` + `nowIso` in page data; islands recreate the same locale for char-count text only.
- Plural keys: `discussion.replyCount`, `comment.showReplies`, `reactions.agreeCount`, …

## Focus behaviour

| Event | Behaviour |
|-------|-----------|
| Validation error | First invalid field focused; errors in `role="alert"` region |
| Successful comment POST | 303 redirect; optional `#focus` query handled by host |
| Report dialog | Open via URL `?report=` — focus moves to dialog panel |
| Sort change | Full navigation — no focus steal on passive list refresh |
| Load more | Link navigation — focus follows browser default |

## Manual smoke (required)

1. Tab through thread: skip link → sort → comment → reactions → reply.
2. Screen reader: reaction buttons announce name + pressed state.
3. Zoom 200% / 400%: composer and thread remain usable at 320px width.
4. Dark mode + forced colors: verify focus ring on links/buttons.
5. `prefers-reduced-motion`: no essential information in motion-only cues.
