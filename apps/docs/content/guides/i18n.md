# Internationalization

Otok does not ship a core i18n runtime. Use optional route segments and loaders.

## Locale in the URL

```text
src/app/routes/[[lang]]/about.tsx   → /about and /:lang/about
```

```tsx
const messages = {
  en: { title: "About" },
  de: { title: "Über uns" },
} as const;

export const loader = ({ params }) => {
  const lang = params.lang === "de" ? "de" : "en";
  return { lang, copy: messages[lang] };
};

export const head = ({ data }) => ({
  title: data.copy.title,
  lang: data.lang,
});

export default function About({ data }) {
  return <h1>{data.copy.title}</h1>;
}
```

## Typed links

```ts
import { route } from "virtual:otok-routes";

route("/[[lang]]/about", { params: { lang: "de" } });
```

## With `@kamod-ch/otok-i18n`

Optional composition package for locale resolution, catalogs, and `t()` — still not part of Otok core.

```ts
// src/app/routes/[[lang]]/_middleware.ts
import { createI18nMiddleware } from "@kamod-ch/otok-i18n/middleware";
import { i18nConfig } from "../../features/i18n.js";

export default createI18nMiddleware(i18nConfig);
```

```ts
import { readI18n } from "@kamod-ch/otok-i18n/middleware";
import { i18nHead } from "@kamod-ch/otok-i18n";

export const loader = ({ hono }) => {
  const i18n = readI18n(hono)!;
  return { locale: i18n.locale, title: i18n.t("about.title") };
};

export const head = ({ data }) => i18nHead(data.locale, { title: data.title });
```

See the [package README](https://github.com/kamod-ch/otok/tree/main/packages/otok-i18n#readme) for route helpers and the Preact client provider.

## Recommendations

- Keep message catalogs at the app layer (JSON, TS modules, or `@kamod-ch/otok-i18n`).
- Prefer URL locale for shareable links; cookie locale can seed defaults.
- Do not add i18n dependencies to Otok core.
