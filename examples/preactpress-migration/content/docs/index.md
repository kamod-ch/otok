Welcome to the **PreactPress → Otok** migration reference.

This site demonstrates how a PreactPress-style documentation page maps to Otok + `@kamod-ch/otok-content` while keeping the PreactPress product identity.

## Features in this example

- Documentation navigation (sidebar + top nav)
- Markdown rendering with table of contents
- Local search index
- i18n (English / Deutsch)
- Sitemap and RSS via SEO plugin
- Dark mode via Kamod
- Custom PreactPress-styled theme
- Version switcher (v1 / v2)

See [Getting started](/docs/getting-started) and [Markdown examples](/docs/markdown-examples).
