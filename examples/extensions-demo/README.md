# Official Extensions Demo

Demonstrates all four official Otok extensions together:

- `@kamod-ch/otok-mail` (test provider + preview)
- `@kamod-ch/otok-storage` (test provider)
- `@kamod-ch/otok-queue` (test provider)
- `@kamod-ch/otok-stripe` (test provider)

```bash
pnpm install
pnpm dev
```

Visit `/__otok-mail/preview` to inspect captured mail.
